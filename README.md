# 🧮 Smart Calculator

A modern responsive calculator built using HTML, CSS and JavaScript.

## 🚀 Features

- Basic arithmetic operations
- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal calculations
- Delete button
- Clear button
- Keyboard support
- Calculation history
- Dark mode
- Light mode
- Scientific calculator functions
- sin
- cos
- tan
- square root
- logarithm
- natural logarithm
- square
- Pi
- Responsive design
- Error handling

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Math Object
- Responsive Web Design
